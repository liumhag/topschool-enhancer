# Chrome Web Store 審查說明稿

## 測試前提

此擴充功能只在公開可存取的 TopSchool 相簿頁面作用，不需要提供測試帳號。如果審查時目標頁面改為需要登入，請在送審前補充合法的測試帳號或公開測試頁面，勿提供含真實兒童私人內容的個人帳號。

## 測試步驟

1. 開啟任一 `https://<school>.topschool.tw/Activity/School-Albums` 頁面。
2. 確認原網站分頁控制已隱藏，向下捲動後會接續載入後續相簿。
3. 進入相簿，確認照片頁會連續載入。
4. 點擊頁面右下角的下載按鈕或瀏覽器工具列圖示，開啟下載器。
5. 點擊「掃描網頁相簿列表」，確認擴充功能只讀取網站相簿列表並顯示下載狀態。
6. 點擊「選擇資料夾」，授權一個測試資料夾。
7. 選取一本相簿並下載，確認只在本機建立一個 ZIP 與索引 JSON。
8. 如需核對，點擊「完整掃描比對」比較網站照片數與 ZIP 檔案數。

## 安全與資料處理

- Manifest V3。
- 不執行遠端程式碼。
- 不包含廣告、分析或追蹤服務。
- 不上傳相簿、照片、瀏覽紀錄或下載紀錄。
- 僅在 TopSchool 相簿路徑執行。
- 本機資料夾存取必須由使用者主動選擇或重新確認授權。
