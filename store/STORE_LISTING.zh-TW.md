# Chrome Web Store 上架文字

## 名稱

TopSchool Album Enhancer

## 簡短說明

TopSchool 相簿連續瀏覽、下載紀錄與本機 ZIP 備份工具。

## 完整說明

TopSchool Album Enhancer 協助可正常瀏覽 TopSchool 相簿的使用者，更方便地瀏覽及備份相簿內容。

主要功能：

- 將相簿列表及相簿照片的分頁內容連續載入。
- 可下載單本、多本或目前列表中的全部相簿。
- 每本相簿分別建立 ZIP，並整理安全、易讀的檔名。
- 保存下載紀錄，快速辨識已下載及新增相簿。
- 可選擇本機資料夾，並視需要完整比對網站照片數與 ZIP 檔案數。
- 所有照片只在瀏覽器與本機處理，不會上傳至開發者伺服器。

適用範圍：`*.topschool.tw` 的 TopSchool 相簿列表與相簿照片頁。目前原圖下載支援相簿頁面所使用的已驗證圖片來源。

本擴充功能不是 TopSchool 或個別學校的官方產品。請只保存自己有權存取及使用的內容。
